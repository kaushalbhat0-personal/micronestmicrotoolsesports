# Deferred Decisions (P5 — explicit)

1. **Additional tools.** Roster/slot builder (privacy review for pasted data),
   tie-breaker (needs competition-rule decisions), qualification calculators,
   and any media tools are NOT approved by shipping this foundation. Each
   needs its own spec + boundary proposal.
2. **Homepage pillar status.** One working tool does not satisfy a "tools
   ecosystem live" claim. The roadmap strip and marketing sections stay
   unchanged until a defined toolset threshold is agreed with owners.
3. **Share URLs / history / accounts.** Explicitly not built; would introduce
   persistence, identity, and moderation questions.
4. **Sitemap/indexing.** Tools routes ship `noindex` (directory posture,
   P1–P4 parity). Indexing change needs an owner decision.
5. **Monetization.** No free/paid flags, no entitlement model, no billing.
   The catalogue contract reserves room for a future flag — approval NOT granted.
6. **Currency expansion.** INR + USD only. More currencies need formatting +
   rounding review per currency (no-subunit currencies, cash rounding).
7. **Game-specific engines.** No per-game calculation rules exist yet; the
   `gameKeys` contract supports them when a genuine rule difference appears.
8. **Corrections/feedback.** No in-product reporting for tool errors; users
   have no channel to flag a miscalculation beyond normal support.
