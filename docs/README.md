# Docs — Greenfield

This directory will hold new product and architecture documentation for the
MicroNest Esports discovery and opportunity platform.

Product pillars (no implementation yet):

1. Players seeking players, teams, organizations and opportunities.
2. Teams seeking players and visibility.
3. Organizations discovering players and teams, managing esports presence,
   and publishing recruitment vacancies.
4. Brands discovering players, teams and organizations, exploring
   partnerships, and publishing opportunities or vacancies.
5. Esports news (supporting section).
6. Tournament discovery and participation information (supporting section).
7. Mini games as a secondary engagement layer.

Discovery and connections are the primary product. News, tournaments and
mini games are supporting sections.

Legacy documentation is preserved for reference under
`ref/legacy-platform/docs/`, `ref/legacy-platform/ARCHITECTURE.md` and
`ref/legacy-platform/README.md`. Do not treat legacy docs as the new
architecture.
